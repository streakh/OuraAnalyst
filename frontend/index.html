Data Privacy & Security Information

Data Handling:

  • Your Oura API key is stored locally in your environment configuration and used solely to fetch data from your Oura account via the official Oura v2 API.
  • Fetched Oura data (e.g., sleep, activity, readiness) is stored locally in the MongoDB database running on your machine. This database has authentication and is bound to localhost to enhance its security.
  • This Oura data does not carry any personal identifiers or Oura account information.
  • When you submit a query, the query text and potentially relevant segments of your stored Oura data are sent to the OpenAI API (specifically, the model used for generating insights).
  • If you would like to view the exact data used for a specific query, you can click the "See full JSON" button in the response card.
  • No data is intentionally shared with any other third parties.

Security Measures:

  • API keys (Oura, OpenAI) are managed via local environment variables, not hardcoded in the application.
  • Local MongoDB access requires authentication.
  • Network access to the local MongoDB instance is restricted to your local machine (localhost).

Risks & Disclaimers:

  • Using any third-party API (Oura, OpenAI) carries inherent risks. Please review their respective privacy policies.
  • While measures are taken to secure your local data and API keys, the overall security also depends on the security of your own computer and network environment.
  • The insights provided are generated by an AI model based on your data and are for informational purposes only. They do not constitute medical advice. Consult with a qualified healthcare professional for any health concerns.
  • Use this application at your own risk.
